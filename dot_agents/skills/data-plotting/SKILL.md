# データグラフの作図規約

グラフを作成、修正、レビューするときは、作業前に [詳細規約](references/plotting-rules.md) を最後まで読む。ユーザーまたは掲載先が別の指定をしている場合は、その指定を優先する。

次の順で判断する。

1. データを歪めない。
2. 軸、値、単位を読み取れるようにする。
3. 比較対象を色以外の符号も含めて識別できるようにする。
4. 複数の図で尺度、色、表記を統一する。
5. 最後に見た目を整える。

作図には原則として Python と Matplotlib を使う。ユーザーが環境を指定した場合は従う。完成した図は同じ描画処理から SVG と PNG の両方を出力し、最終掲載サイズ、カラー表示、モノクロ表示で確認する。元データ、作図スクリプト、設定、単位換算を再生成可能な形で残す。
