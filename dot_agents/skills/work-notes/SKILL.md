# Work Notes

既存の作業記録があれば使用し、なければリポジトリ直下の `NOTES.md` を使用する。

`YYYY-MM-DD HH:MM`形式の見出しを付け、ファイルの末尾へ追記する。正式な仕様書や報告書として整えず、何をしたか、なぜ行ったか、何が分かったか、次に何をするかを短い文章で残す。

判断を変更した理由、重要な実験結果、実験ディレクトリ、関連するコミットは、後から経緯を追うために必要な場合だけ記録する。変更ファイルの羅列、会話の経緯、一般的な説明は省く。

既存の記録がある場合は、その文体、並び順、詳しさに合わせる。
